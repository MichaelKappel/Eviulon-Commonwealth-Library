The priority is maximum public access and machine understanding, not monetization.

**GitHub review branch now includes:** the complete, SHA-matched `Library_Website/datasets/books/*.md` text and `Library_Website/datasets/data/books/train.jsonl`, with 14 owner-authorized official works. The searchable PDFs and EPUBs remain in the separate validated download package and are **not** committed to GitHub. Public website deployment remains unverified.

## Integrity and responsible publication

1. Preserve the 5,105 source records and 260 protected `.uai` records; **never push private `.uai` or `PRIVATE_MASTER` data to GitHub**.
2. Only official-book text is owner-authorized. The 210 separately labeled supplemental research records are not covered by the book-text license.
3. Require source SHA-256 verification for all manuscript exports. Do not generate invented text or attribute text spans to print pages when Markdown-to-PDF page mapping is not verified.
4. Keep deployment, GitHub publication, crawler access, model ingestion, and training as separate evidence categories.
5. Review any existing publication or retailer exclusivity terms before public hosting; the owner's permission statement cannot cancel third-party contracts.

## Review gate

The owner-authorized exact-source import and strict CI allowlist now reside on the same draft branch. The allowlist pins all 14 Markdown hashes and the full JSONL hash and preserves only two pre-existing public-safe `.uai` notes by their unchanged Git blob hashes; it rejects any other `.uai`, research bulk, non-approved manuscripts, credentials and binary releases. **Do not merge while CI is failing; investigate the check and confirm protection is passing.** The main branch and live website have not been changed by this GitHub import.
