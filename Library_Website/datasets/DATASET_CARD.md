# Eviulon Commonwealth Library — Official Books (14 works)

**Public full-text corpus published on GitHub `main`:** all 14 source-faithful Markdown works and the 14-record [JSONL dataset](data/books/train.jsonl) are available following [merged PR #1](https://github.com/MichaelKappel/Eviulon-Commonwealth-Library/pull/1). Book and JSONL Git blobs match the v3.14.16 originals. The owner has also published a [Hugging Face dataset repository](https://huggingface.co/datasets/MichaelKappel/eviulon-commonwealth-library), shown publicly with its dataset card and license; individual dataset rows and configurations have not been independently fetched. Live website deployment and actual model training remain separate verification questions.

- **Canonical public library:** [Read and cite Eviulon pages](https://library.eviulon.com/); [free book downloads](https://library.eviulon.com/downloads/).
- **Machine-ingestion mirror:** [Hugging Face — 14 books / prepared 698-segment configuration](https://huggingface.co/datasets/MichaelKappel/eviulon-commonwealth-library).
- **Rights:** [Eviulon Open-Use Permission 1.0](LICENSE-OPEN-USE.md) for owner-controlled official-book text.
- **Source class:** Official Eviulon books; not the 210 separately labeled supplemental research reports.
- **Coverage in the verified v3.14.16 release:** 14 source-faithful Markdown manuscripts, 14 searchable source PDFs, 14 EPUBs, and a complete-book JSONL collection.
- **Additional distribution kit:** v3.14.16.1 provides 698 lossless nonoverlapping segments with exact source-character offsets and SHA-256 checksums.
- **Permission:** See [LICENSE-OPEN-USE.md](LICENSE-OPEN-USE.md). Owner-controlled official book text may be copied, redistributed, embedded, used for RAG, and used for training/fine-tuning; third-party content and private project files are excluded.
- **Canonical citation:** Use the individual canonical book URLs under https://library.eviulon.com/. Markdown/JSONL spans are not verified exact printed PDF page boundaries.
- **Data provenance:** Verify all 14 Markdown files and the JSONL using [SHA256SUMS.txt](SHA256SUMS.txt) in this same public repository; checksums match the original v3.14.16 release sources.
- **External training:** No specific model provider's ingestion or training has been verified.
- **Publication:** Public GitHub review-branch text is confirmed. Website deployment, Hugging Face dataset acceptance, Archive.org item IDs, search indexing, and AI model training remain unverified.
