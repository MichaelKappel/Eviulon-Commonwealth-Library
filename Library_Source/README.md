# Eviulon source-library public metadata

The full production source library and original `.uai` memory are **private** and intentionally not present in this GitHub release. This folder exposes bibliographic records and official links only, so agents may find the books without downloading manuscripts.

- [All books and deep links](../README.md#all-14-books--canonical-deep-links)
- [Metadata JSON](metadata/books.json)
- [Bibliographic JSON-LD](metadata/books.jsonld)
- [Public agent guidance](AGENT_DISCOVERY.md)
- [Canonical online library](https://library.eviulon.com/)

Public-safe rune-encoded `.uai` and `AGENTS.md` records are identity/provenance **summaries created for this release**, not exports of private memory.
