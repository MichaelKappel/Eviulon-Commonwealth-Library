The public GitHub repository contains its documentation, public metadata, and website implementation. It does **not** include a free license to Eviulon book text, EPUB/PDF production files, private machine memories, or third-party quotations.

- **Browsable:** The canonical site exposes public HTML for authorized online reading and source citation.
- **Crawl access:** Robots.txt controls cooperating crawlers; it is not copyright permission, DRM, guaranteed training approval, or an indexing command.
- **Bulk reuse:** Do not redistribute the full text, publish a model-training dataset, or attach a Creative Commons license to the manuscripts without confirming author rights, third-party materials, retailer exclusivity, and publication approvals.
- **Future training:** If rights are cleared, release a **separately versioned** rights-approved dataset with a dataset card, edition/provenance hashes, explicit permitted-use terms, and documented corrections. Links to the canonical page URLs should survive dataset export.
